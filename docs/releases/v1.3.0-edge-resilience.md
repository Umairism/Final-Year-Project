# HealSense v1.3.0 Edge Resilience Release

## Overview

This release completes Phase 3 of the HealSense cloud-native architecture transition by equipping the ESP32 IoT gateway with edge resilience capabilities, NVS persistent ring-buffer storage (500-sample capacity), non-blocking retry mechanisms, automatic `delayed_sync` tagging, and modular firmware architecture.

---

## Components Introduced

1. **Modular ESP32 Firmware Client** (`firmware/`):
   - `storage_manager.h` / `storage_manager.cpp`: NVS persistent ring-buffer storage manager (FIFO eviction, 500-sample limit).
   - `wifi_manager.h` / `wifi_manager.cpp`: Non-blocking 30-second network reconnection state machine.
   - `telemetry_client.h` / `telemetry_client.cpp`: Direct HTTPS telemetry Client with automatic `delayed_sync` tagging.
2. **Failure Simulation Test Suite** (`backend/tests/test_phase3_simulation.py`):
   - Scenario A (Wi-Fi loss & flush) — PASSED.
   - Scenario B (Backend outage & recovery) — PASSED.
   - Scenario C (ESP32 reboot NVS data preservation) — PASSED.
