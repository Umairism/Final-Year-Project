# HealSense v1.2.0 Telemetry Ingestion Release

## Overview

This release introduces direct cloud telemetry ingestion (`POST /api/v1/telemetry`) allowing ESP32 hardware devices to stream physiological telemetry directly to the FastAPI cloud backend with `X-Device-API-Key` header authentication.

---

## Features Introduced

1. **Direct Ingestion Endpoint**: `POST /api/v1/telemetry` accepting `TelemetryPayload`.
2. **Device Authentication**: `X-Device-API-Key` header validation against hashed SHA-256 keys in `Device` DB records (`api_key_hash`).
3. **Service Layer Refactoring**: `TelemetryIngestionService` (`api/services/telemetry_service.py`) handles device auth, patient mapping, database storage, LSTM prediction execution, deterministic rule evaluation, fusion scoring, and WebSocket real-time events.
4. **Patient Route Refactoring**: `POST /api/v1/patients/{patient_id}/vitals` internally reuses `TelemetryIngestionService` to eliminate duplicate code paths.
5. **Robust ML Fallback**: Wrapped native TensorFlow imports in prediction service to gracefully fallback to rule-based evaluation if binary C-extensions are missing in runtime environments.
