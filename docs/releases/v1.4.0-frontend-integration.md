# HealSense v1.4.0 Frontend Integration Release

## Overview

This release completes Phase 4 of the HealSense cloud-native roadmap by delivering a complete real-time clinical monitoring web dashboard connected directly to the FastAPI cloud backend, WebSocket stream (`telemetry.ingested`), PostgreSQL database, Hybrid Risk Fusion engine, and Gemini Decision Support explanations.

---

## Features Delivered

1. **API Client & Telemetry Services** (`src/services/`): `apiClient.ts` & `telemetryService.ts`.
2. **WebSocket Ingestion Hook** (`src/hooks/`): `useTelemetrySocket.ts`.
3. **Clinical Vitals Cards**: Specialized components for HR, SpO2, Temperature, and Blood Pressure with acquisition source badges (`BLE Cuff`, `Manual Entry`, `Hardware UART`, `No BP Recorded`) and `Delayed Sync` indicators.
4. **Risk & Explainability**: `RiskGauge.tsx` and `GeminiExplanationCard.tsx` ("Decision Support Explanation").
5. **Historical Timeline**: Recharts `VitalTrendChart.tsx`.
6. **Device Gateway Page**: `/devices` monitoring page.
